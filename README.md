# Jam Roulette

A band practice game. Roll a drum beat, a rhythm guitar strum that grooves with it, and a few chords that go together, then jam inside those constraints. Lock what you like, roll the rest. Optional Change-up mode re-rolls one part every few bars, and Challenges gives each player a rule to stick to.

**Play it:** https://x14halo.github.io/jam-roulette/

- 184 strum and fingerpicking patterns based on real rhythm-guitar parts (rock, pop, country, blues, funk, soul, reggae, jazz, Latin, heavy), matched to the drum style, tempo and swing
- 216 chord progressions used in real songs, with guitar fingerings, in guitar-friendly keys
- Drums from [Pocket Drummer](https://x14halo.github.io/pocket-drummer/)

## Sounds

- Drum kit: [Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums) by Versilian Studios (CC0)
- Guitars: Fluid R3 GM by Frank Wen (CC BY 3.0) and Musyng Kite (CC BY-SA 3.0), via [midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)

The whole app is a single self-contained `index.html`.
